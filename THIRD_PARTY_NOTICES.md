## Installed with Drollery (not part of this repository)

These are fetched from PyPI or the operating system when you install or build it; they keep their own licenses.

| Component | Used for | License |
|---|---|---|
| FastAPI, Starlette | web framework | MIT / BSD-3-Clause |
| pydantic | settings and request models | MIT |
| AnyIO | threads and cancellation in async code | MIT |
| Uvicorn | server | BSD-3-Clause |
| Jinja2, MarkupSafe | templates | BSD-3-Clause |
| python-multipart | uploads | Apache-2.0 |
| httpx | outgoing requests | BSD-3-Clause |
| segno | QR codes for two-factor setup | BSD-3-Clause |
| yt-dlp | downloading media from links | Unlicense |
| gallery-dl | downloading image galleries from links | GPL-2.0-only |
| FFmpeg (Debian package in the Docker image) | thumbnails, probing, audio splitting | LGPL/GPL, depending on the build |

`yt-dlp`, `gallery-dl` and `ffmpeg` are separate programs that Drollery starts as sub-processes; none of their code is
linked into or copied into Drollery.

### Optional speech-to-text container

The compose file can start [Speaches](https://github.com/speaches-ai/speaches) (MIT) with `faster-whisper` models
(MIT, from the Systran model hub). It is off by default and downloads its model on first use.

## Online services (only when you press the button)

Drollery contacts these only when you ask for a lookup or add a link, and sends the minimum (see the README, "Privacy").
Their data and images are governed by their own terms.

- **MusicBrainz** — core data is CC0; please keep to its rate limit and give a contact URL in `metadata_user_agent` if
  you query a lot. **Cover Art Archive** — cover images carry their individual licenses; Drollery fetches a cover only
  when you pick it, for your own library.
- **IMDb** — only the public search suggestion endpoint used by imdb.com's own search box is queried; it is
  unofficial and may change. IMDb's [conditions of use](https://www.imdb.com/conditions) apply to its data.
- **OMDb** — needs your own API key; see <https://www.omdbapi.com>.
- **TMDB** — needs your own API key. *This product uses the TMDB API but is not endorsed or certified by TMDB.*
  See <https://www.themoviedb.org/api-terms-of-use>.
